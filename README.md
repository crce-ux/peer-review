# peer-review

**期刊同行评议的完整流程**——从决定是否接受邀请，到写出可辩护的审稿意见。

---

## 定位

编辑请你做的是「**领域内同行技术把关 + 提供独立判断**」。

**不是替作者重写论文，也不是当执法者。**

这句话决定了后面所有措辞的分寸。

---

## 它覆盖什么

| 阶段 | 内容 |
|---|---|
| **接不接** | 24–48 小时内回复；能力 / COI / 时间 / 新颖性四问 |
| **怎么读** | 三遍阅读法：整体扫描 → 方法学深审 → 细节挑错 |
| **怎么审** | 逐章节审查要点，按研究类型分支（RCT / 观察性 / EEG / ML / 系统综述） |
| **怎么写** | Summary + MAJOR + MINOR 结构；中英范例；给编辑的保密意见 |
| **领域清单** | ⭐ **TRS / EEG / 机器学习三份专属核查清单** |
| **伦理** | COPE 五项义务；诚信红线；五类常见陷阱 |

---

## 最有价值的部分：领域专属核查清单

精神医学审稿的「含金量」往往就在领域细节上。**别人审不出来的，往往是你恰好懂的。**

举三条最容易放过的：

| 领域 | 硬伤 |
|---|---|
| **TRS** | **依从性未评估**——TRS 研究最经典的一条 |
| **EEG** | **组间 trial 数不平衡**——本身就是偏倚，且常被当作细节忽略 |
| **ML** | **特征选择在全集上做过**——最常见的泄漏点 |

完整清单见 `references/domain-checklists.md`。

---

## 三条最容易被违反的纪律

1. **诚信疑虑只写进给编辑的保密意见**，不写进给作者的意见。
2. **不给没有依据的偏好**。「我认为应该用 X 方法」不是理由；「该方法在当前设计下的局限是…」才是。
3. **疑似造假不自行调查**——写进保密意见，编辑走 COPE 流程。
