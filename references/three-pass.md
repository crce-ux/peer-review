# 逐章节审查要点

## 动手前准备

1. **读编辑邀请信**——有的期刊给了审稿人指南与明确评分维度
2. **核对文件完整性**：正文、补充材料、图、表、注册信息。缺件在意见开头或给编辑处说明
3. **检索作者既往相关工作**（PubMed / Scholar）——判断 novelty gap 是否被诚实交代、是否有自我重复（salami / split publication）
4. **核对报告规范**：RCT→CONSORT；观察性→STROBE；系统综述→PRISMA；**预测模型 / ML→TRIPOD**；诊断→STARD
5. **准备草稿页**：第一遍随手记「印象笔记」，最后再组织成正式意见

---

## 标题与摘要

- 摘要是否结构化、数字是否与正文一致
- 结论是否夸大（「证明」vs「提示」）
- 标题是否如实——**警惕把相关性写成因果**

---

## 引言

- 是否交代了**真实的研究空白**，而非自说自话
- 是否引用了最相关 / 最新的同类研究
  （遗漏关键文献 = 可能没做足功课，或**故意回避**）

---

## 方法（按研究类型分别盯）

### RCT / 干预研究
- 随机化方法（序列生成 + 隐藏分配）、盲法（患者 / 评估者 / 统计师）及盲法检验
- **是否先注册**（ClinicalTrials.gov / ChiCTR）、注册号是否给出、**主要终点是否一致**
- 样本量：基于什么假设（效应量来源、脱落率）；实际脱落与分析人群（ITT vs PP）
- 治疗剂量 / 时长是否「充分」——精神分裂症要对照 **TRRIP 标准**判断足量足疗程

### 观察性研究 / 生物标志物
- 入排标准、招募来源、选择偏倚、混杂处理（匹配 / 校正变量依据）
- 暴露与结局测量时点、盲法评估
- 丢失数据比例与处理方式（多重插补 vs complete-case）

### EEG / ERP 研究
- 记录与预处理全链路的**可复现细节**：电极数 / 参考、采样率、滤波参数、伪迹剔除策略、
  纳入 trial 数（**注意各组间 trial 数是否平衡**）、信噪比
- 分析窗与电极选择是**先验假设驱动**还是**事后数据挖掘**
- **循环分析陷阱**：用同一数据选电极 / 时间窗，又用同一数据检验

### 机器学习 / 预测模型
- 训练 / 验证 / 测试集划分是否干净
  （**特征选择与超参调优只能在训练集内做**——最常见的泄漏点）
- 是否用嵌套交叉验证 + 独立测试集；类别不平衡如何处理（不应只报 accuracy）
- 显著性是否经置换检验；是否报告**校准度**与决策曲线，而不只 AUC

### 系统综述 / Meta 分析
- 检索式是否可复现（数据库 + 日期 + 完整式）
- 是否双人独立筛选提取、偏倚评估工具
- 异质性（I² + tau²）与亚组 / 敏感性 / 发表偏倚分析

---

## 结果

- 基线表是否给出
- **是否同时报告效应量与置信区间**（只报 p 值是常见通病）
- 次要 / 探索性分析是否与主要分析明确区分；多重比较是否校正
- 结果文字是否客观（「结果提示」而非「本研究证明」）

---

## 讨论

- 是否**过度引申**（人群外推、因果推断、临床建议）
- 局限性是否诚实（脱落、样本量、单中心、无盲法、随访短、仅相关）
- 是否把「未检验的机制解释」当成事实陈述

---

## 伦理与声明（现在几乎每稿必查）

- 伦理审批机构与编号、知情同意、数据 / 代码可用性声明
- 作者贡献 / CRediT、利益冲突声明
- **AI 使用是否按期刊政策披露**（ICMJE / COPE 要求声明写作或图表中是否使用 LLM）
- **图像完整性**：有无拼接、旋转重复、异常裁剪（必要时提示编辑核查原图）

---

## 时间参考

| 阶段 | 建议耗时 |
|---|---|
| 决定是否接受 | <48 h |
| 第 1 遍扫描 | 0.5–1 h（同时查 novelty） |
| 第 2 遍方法学 | 2–4 h（复杂稿 4–6 h） |
| 第 3 遍细节 | 0.5–1 h |
| 撰写意见 | 1–1.5 h |
| **合计** | **约 4–8 h / 稿** |

> 第 2 遍**可拆两天**——避免疲劳误判。

**大修稿回来（re-review）只核对三件事**：是否逐条回应、修改是否合理、有无引入新问题。
**不必重新全程审。**
