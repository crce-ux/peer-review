# 正反样例

同一篇稿子，同一个结论（Major Revision），两份意见。**左边提交会挨骂，右边不会。**

---

## 一、整份意见

### ❌ 不好

```
该研究存在严重的方法学问题，结论不可靠。

1. 统计方法使用不当。
2. 样本量太小，缺乏说服力。
3. 结果解释过度。
4. 参考文献陈旧。
5. 语言需要润色。

建议大修。
```

五条全部不达标：**没有一条指向位置、没有一条给出方向、没有一条说明为什么重要**。
作者看完不知道改什么。

### ✅ 好

```
稿件编号：PSY-D-26-03918　标题：氯氮平抵抗患者屏状核功能连接与疗效的关联
审稿建议：Major Revision

摘要：作者用 42 例 TRS 患者的静息态 fMRI，检验屏状核—前额叶功能连接能否预测
12 周氯氮平疗效，主终点为 ΔPANSS 与 ΔAUC 的关联。样本量在该病种里属少见，
数据采集规范。但**核心假设的前提未验证**，且主要分析未按预注册执行——
这两点影响结论的可信度，其余为报告完善。

1.（Methods 2.2 / Line 118）依从性未评估，但全文默认患者「已足量足疗程」。
   氯氮平抵抗的定义以依从性为前提，而依从性由谁评估、用什么方法评估、
   结果如何，正文与补充材料都没有交代。若纳入者中存在未达有效剂量者，
   他们本不属 TRS，会稀释关联。
   → 请补充依从性评估方法（血药浓度 / 药房记录 / 家属确认），
     并做一次仅保留血药浓度达标者的敏感性分析。

2.（Methods 2.4 / Line 156）SAP 注册为使用「多重插补」，实际用的是完整案例分析
   （合并附表 S2 的 n 数与正文不符可见）。未见偏离说明。
   → 请说明偏离原因与决定时点；或按注册方案重跑多重插补，两者都报。

3.（Results 3.2 / Table 2）报告了 p 值，未报效应量与 95%CI。
   → 请补齐每个主要关联的 r 与 95%CI。

4.（Results 3.3 / Table 3）亚组按年龄、病程、基线 PANSS 三分，共 9 次比较，
   未见多重比较校正，主文亦未标注为探索性。
   → 请标明为探索性分析，或给出校正后的结果。

5.（Discussion，第 3 段）「屏状核连接下降提示氯氮平反应性受损」——
   本研究为横断面关联，未含因果设计。
   → 请把措辞改为关联性表述，并说明因果方向无法由本设计推断。

给编辑的保密意见（不向作者展示）：第 2 条所涉偏离若确系事后决定，
属报告完整性问题而非数据问题，但需作者明确说明。
```

**差在**：每条都有位置、有为什么、有可执行要求；摘要让作者确认「审稿人读懂了」；
诚信疑虑留在给编辑的部分。

## 二、单条意见的五组对照

| ❌ | ✅ |
|---|---|
| 统计方法不对。 | （Methods 2.6 / Line 203）重复测量用了 4 次独立 t 检验，未校正时间点间的相关性；SAP 写的是 MMRM。→ 请按 SAP 重跑，或说明改用 t 检验的理由。 |
| 样本量小。 | （Methods 2.1 / Line 96）未见样本量依据。42 例是否达到检验效能 0.8？→ 请补样本量估算，或明确标注为探索性。 |
| 应该用 X 方法。 | （Methods 2.3）当前用的线性混合模型假设缺失随机；若失访与病情相关则不成立。→ 请补一次敏感性分析（如 pattern-mixture 模型）检验该假设的影响。 |
| 语言需要润色。 | （全文）第 2 段与第 5 段的「significant」混用了「统计显著」与「临床重要」两种含义。→ 请统一用法，临床意义用 substantial/meaningful。 |
| 结论过度。 | （Discussion，末段）「本指标可作为 TRS 筛查工具」——本研究未评估灵敏度与特异度，也无独立验证集。→ 请删除该表述，或补诊断准确性分析。 |

## 三、给编辑的保密意见

### ❌ 不好

```
这篇文章数据可能是编的，建议拒稿。作者的单位我认识，水平一般。
```

两处越界：**自行下了造假结论**（应走 COPE，不由审稿人裁断）；
**引入了与稿件无关的个人评价**。

### ✅ 好

```
与作者意见同步的评审建议：Major Revision。

需要编辑注意的两点：
1. 具体关切：Results 3.1 报告 n=42，而 Table 1 的性别与年龄分项相加为 44。
   我在给作者的意见里未提此项，建议编辑核对原始数据后再决定如何询问。
2. 作者声明无利益冲突；但我与该团队近三年无合作，评审独立性无问题。
```

**差在**：不自行裁断、不引无关信息、把需要编辑判断的事单列出来。
