# 领域核查：一套生成轴 + 三份样例

> 审稿的价值往往就在领域细节上。**别人审不出来的，往往是你恰好懂的。**

---

## 〇 · 先给轴：领域问题都落在这五层

拿到**任何一个领域**的新稿件，逐层问一遍——**得到的答案就是你所在领域的核查清单**。

| 层 | 问什么 | 答得出来的例子 |
|---|---|---|
| **① 定义层** | 核心概念的**名义定义 vs 操作定义**有落差吗？术语有没有被混用？ | 「难治」到底怎么算——共识，还是作者自定义 |
| **② 前提层** | 有没有**大家默认成立、却从未验证**的前提？ | TRS 研究默认「患者真的按医嘱吃够了药」——多数人不验 |
| **③ 测量层** | 测量链路每一步**可复现**吗？**组间可比**吗？ | EEG 各组纳入分析的 trial 数是否平衡 |
| **④ 分析层** | 信息有没有**越界流动**？多重比较？验证是否独立？ | 特征选择在**全集**上做过——泄漏 |
| **⑤ 报告层** | 报告规范 checklist 用对了吗？ | 预测模型该用 TRIPOD，不是 STROBE |

> ⭐ **一个要紧的区分：该枚举的地方枚举，该生成的地方生成。**
>
> **⑤ 报告层**是国际共识的**穷举**清单——直接查表（见下）。
> **①–④ 领域问题**无法穷举（永远有下一个领域）——**用轴生成**。
>
> 下面三份样例，就是这套轴**生成出来的产物**。它们不是"清单里最好的三份"，
> 而是"三个示范：看轴怎么落地"。**换领域时，按同一套轴自己做一份。**

### 报告规范速查（⑤ 层 —— 枚举即完备）

| 研究类型 | 规范 |
|---|---|
| RCT | **CONSORT**（方案：SPIRIT） |
| 观察性（队列 / 病例对照 / 横断面） | **STROBE** |
| 系统综述 / Meta | **PRISMA** |
| 诊断准确性 | **STARD** |
| 预测模型 / 机器学习 | **TRIPOD**（AI 方向：TRIPOD-AI） |
| 动物实验 | **ARRIVE** |
| 病例报告 | **CARE** |
| 定性研究 | **SRQR** / **COREQ** |
| 质量改进 | **SQUIRE** |
| 卫生经济学评价 | **CHEERS** |

## 样例 A · 难治性精神分裂（TRS）→ 落在 ① 定义层 + ② 前提层

- [ ] 是否明确定义「难治」：通常 = **≥2 种不同抗精神病药**、各**足量**（氯丙嗪当量，一般 ≥400–600 mg/d）**足疗程**（≥4–6 周）后症状仍明显
- [ ] 是否引用权威共识（**TRRIP consensus**, Howes et al. 2017；**Kane 标准**）
- [ ] 剂量是否折算并报告**氯丙嗪当量**；疗程证据（病历记录 vs 自报）
- [ ] 是否区分「氯氮平抵抗 / 超难治」（clozapine-resistant / ultra-resistant TRS）——**术语是否被混用**
- [ ] **依从性如何确认**（血药浓度 / 监护给药）
      ⚠️ **漏掉依从性评估是 ② 前提层的经典标本**：整篇研究默认患者吃够了药，而这一点从未被验证
- [ ] PANSS / POS / NOS 等量表是否由**盲法、经过培训**的评定者施测；评定者间信度是否报告

## 样例 B · EEG / 电生理（MMN、qEEG、TMS-EEG）→ 落在 ③ 测量层

- [ ] 记录参数完整可复现：电极系统 / 通道数、参考与重参考、采样率、
      在线 / 离线滤波带宽、阻抗标准
- [ ] 伪迹剔除策略（阈值 / ICA / 目检），**剔除比例是否报告、组间是否可比**
- [ ] **纳入分析的 trial 数是否报告**（MMN 尤其要报：保留数 / 总刺激数）
      ⚠️ **组间 trial 数不平衡本身就是偏倚**——这是 ③ 测量层"组间可比"的标本
- [ ] 分析时间窗、电极选择是**先验**还是数据驱动；若数据驱动，是否有独立验证或说明
- [ ] 与临床变量（症状、用药剂量、病程）是否控制或报告相关分析前提
- [ ] TMS-EEG：伪迹（刺激伪迹 / 肌肉伪迹）清理是否交代；是否报告刺激部位 / 强度 / RMT
- [ ] 多重比较（多电极 × 多时窗）是否校正（FDR / 簇置换）；单侧 vs 双侧检验是否说明

## 样例 C · 机器学习 / 预测建模 → 落在 ④ 分析层

- [ ] 样本量是否足够且报告（**events-per-variable** 或类似依据）
      ⚠️ 小样本 + 高维特征是最常见问题
- [ ] **特征选择是否泄漏**（只应在训练集内做）；
      预处理（标准化、插补）是否**仅在训练集拟合后套到测试集**
      ⚠️ **特征选择在全集上做过，是 ④ 分析层"信息越界"的标本**
- [ ] 交叉验证结构：嵌套 CV？独立测试集？随机种子 / 重复 CV 是否报告
- [ ] 类别不平衡处理；指标是否适当（敏感度 / 特异度 / PR-AUC / **校准曲线**，不只 accuracy / AUC）
- [ ] 显著性：置换检验？是否与「零模型」比较
- [ ] 是否有**外部验证**；若没有，是否诚实声明「仅内部验证、外推需谨慎」
- [ ] 是否给出特征重要性 / 模型可解释性；
      **是否与简单基线（如临床量表评分）比较过增量价值**
- [ ] 代码 / 特征是否开源或按政策可获取

## 通用层 · 统计与报告（任何设计都过一遍）

- [ ] **效应量与 95% CI 是否给出**（不只 p）
- [ ] 多重比较 / 事后检验是否校正
- [ ] 缺失数据处理方式是否交代；脱落是否用**敏感性分析**检验
- [ ] 正态性检验 / 非参选择、方差齐性是否合理
- [ ] 报告规范 checklist 是否提交（对照上方速查表）

## 用法

**不要逐条问作者，逐条问自己「这一条过了吗」**——过了就不提，没过才写进意见。

这样避免两类失败：
- **把没做的当成没写**（多提了不该提的）
- **把领域惯例当常识跳过**（漏了只有内行才看得出的问题）

### 换到一个新领域时，三步

1. **查 ⑤**：这份稿该用哪份报告规范？对着它的 checklist 走一遍。
2. **走 ①–④**：四层各写 3–5 条你领域里「圈内人才看得出」的问题。
   **写不出来，说明你还不足以审这个领域**——这也是接不接稿的一条自检。
3. **对照样例**：把 A/B/C 当范本，看有实质内容的条目长什么样。
   别写成「请写清楚出处」这种谁都说得出的空话——**等于没有实质内容**。
