# 审稿伦理、诚信红线与常见陷阱

## 一、审稿人义务（COPE Ethical Guidelines）

1. **保密**——稿件内容、审稿意见、作者身份（单盲下）一律不外传；
   **不引用未发表稿件内容**；**不告知他人自己是审稿人**
2. **客观**——基于证据评价，不因作者名气 / 国籍 / 性别 / 机构或个人好恶带偏
3. **及时**——期限内完成；无法按时尽早告知编辑
4. **诚实披露 COI**
5. **不利用信息**——不得借审稿获取的未发表信息**抢先做自己的研究**

---

## 二、科研诚信红线（见到即提示编辑）

| 类型 | 表现 |
|---|---|
| **数字不自洽** | 统计量、df、p 值对不上；正文 / 摘要 / 图表数字不一致 |
| **图像问题** | 拼接、旋转重复、过度裁剪、同一图出现于不同实验 |
| **重复 / 碎片化发表** | 与作者既往论文数据重叠未引用未声明（salami slicing） |
| **选择性报告** | 注册终点与稿件终点不符；只报显著结果 |
| **引用操纵** | 大量自引；引用审稿人文章凑数 |
| **未披露** | COI、伦理审批缺失、AI 使用、样本重叠 |

### ⚠️ 遇到疑似造假的正确做法

**不直接给作者定罪。**

写进**给编辑的保密意见**，给具体位置与依据；编辑 / 期刊会走 COPE 流程。
**审稿人不需要、也不应该自行调查。**

---

## 三、常见陷阱

| ❌ | 说明 |
|---|---|
| 把审稿当成给自己的论文找补引用 / 推销自己工作 | 最容易被编辑识破 |
| 要求作者补充与**你自己偏好**相关、但与研究问题无关的分析 | 越界的典型 |
| 用「我认为应该用 X 方法」代替「该方法在当前设计下的局限是…」 | 前者是**偏好**，后者是**专业判断** |
| 语言暴力、嘲讽式措辞 | 建设性 ≠ 客气，但**必须尊重** |
| 过度要求：要求做成本极高、收益极低的重做实验 | 除非确为结论必需 |

### 一条判断标准

> **你写下的每一条，能不能在作者反驳时被辩护？**
>
> 能引到稿件的具体位置、能说清"为什么这影响结论"——可以写。
> 只能表达"我觉得"——删掉。

---

## 四、提交前 60 秒自查

- [ ] Summary 让作者感到被读懂了吗？
- [ ] 每条 major 都给了「问题 + 理由 + 可执行建议」？
- [ ] 意见是否指向具体位置（章节 / 行 / 图表）？
- [ ] **是否只有偏好、没有依据的评论？**（有则删）
- [ ] 诚信疑虑是否**只**写在给编辑的保密栏？
- [ ] 语气是否尊重、建设性？（有冷嘲热讽就重写）
- [ ] 是否已声明 COI / 无 COI？
- [ ] 每条意见对着「如果我是作者，能否据此修改」过一遍了吗？
